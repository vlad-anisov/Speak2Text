# Speak2Text — техзадание v0.1 (только macOS)

Локальная диктовка: держишь клавишу, говоришь, отпускаешь, и текст вставляется туда, где стоит курсор.
Распознавание: WhisperKit на Neural Engine, без облака.

## Основа
- Код прототипа Dictate (`Sources/dictate`). Live-режим: перераспознавание раз в 1 с с LocalAgreement-2. Ожидание после отпускания 1,25–1,4 с. Это не ломать.
- Swift Package + `build.sh` для сборки `.app` (Xcode нет, только Command Line Tools). macOS 14+, Apple Silicon.
- Bundle ID `io.github.vlad-anisov.speak2text`, версия `0.1.0`.
- Подпись: `Apple Development: Uladzislau Anisau (P3W3R69UM6)`. Подпись постоянная, поэтому разрешения TCC переживают пересборку.
- Установка: `~/Applications/Speak2Text.app`, без sudo.
- Модель по умолчанию — `openai_whisper-large-v3-v20240930_turbo_632MB`. Уже скачана в `~/Documents/huggingface/models/argmaxinc/whisperkit-coreml/`: сначала искать там, потом в `~/Library/Application Support/Speak2Text/Models`.
- Интерфейс на английском и русском, язык по системе.

## Функции
1. **Меню-бар.**
   - Монохромная template-иконка.
   - Пункты: статус, «Настройки…», «Проверить обновления…», «Открыть лог», «Выход».
   - Окна в Dock нет (LSUIElement).
2. **Первый запуск.** Окно разрешений:
   - Микрофон, Мониторинг ввода, Универсальный доступ — у каждого статус ✓/✗ и кнопка «Открыть настройки»;
   - статус обновляется каждые 1–2 с.

   Если разрешение выдано, а процесс его не видит, предложить кнопку «Перезапустить». Подсказка: «Если приложение уже в списке, удалите его кнопкой − и добавьте снова».
3. **Клавиша — любая.**
   - Записать в настройках можно: одиночный модификатор с различением левого и правого (Option, Command, Control, Shift, Fn), любую обычную клавишу (F13, CapsLock и т.д.) или комбинацию (⌃⌥Space).
   - По умолчанию: правый Option.
4. **Два режима.**
   - Удержание (по умолчанию): держишь — запись, отпустил — вставка.
   - Нажатие: первое нажатие — старт, второе — стоп и вставка. Esc — отмена.

   Для модификатора в режиме удержания оставить отмену при нажатии другой клавиши или клика и при удержании меньше 0,4 с. Это защищает обычные сочетания вроде Option+буква.
5. **Плашка (overlay).**
   - Капсула внизу по центру экрана, где сейчас курсор мыши, примерно 220×44, отступ снизу 24.
   - Фон — blur-материал, тёмный и светлый по теме.
   - Состояния:
     - **слушает**: 20–30 столбиков-волна, реагирует на уровень микрофона (RMS → плавная интерполяция, 60 fps);
     - **тишина**: спокойная «дышащая» пульсация;
     - **обработка**: перелив или бегущая точка;
     - **готово**: короткая галочка, затем исчезновение;
     - **отмена**: исчезновение.
   - Появление и исчезновение с анимацией (scale+fade, ~150 мс).
   - Панель не забирает фокус (non-activating NSPanel, ignoresMouseEvents), иначе вставка уйдёт не туда. Это критично.
   - Плашку можно выключить в настройках.
6. **Заглушение других звуков** (включено по умолчанию).
   - На время записи громкость основного устройства вывода опускается до заданного уровня (по умолчанию 0 %, ползунок 0–50 %), после — восстанавливается.
   - Если у устройства нет регулировки громкости, пропустить.
   - Исходную громкость сохранить на диск и восстановить при следующем запуске, если приложение упало во время записи.
7. **Словарь.**
   - **Замены**: таблица «что распознано → на что заменить» (без учёта регистра, по границам слов), например «пайплайн → pipeline». Применяется к финальному тексту.
   - **Слова-паразиты** (выключено по умолчанию): редактируемый список («э», «ээ», «ну», «типа», «как бы», «короче»), удаляются вместе с запятыми рядом.
   - **Подсказки модели (prompt)** (выключено по умолчанию): список терминов отдаётся как prompt в WhisperKit. Предупреждение в UI: «Может пропускать или дублировать слова — проверено в бенчмарке».
8. **Модель и ускоритель.**
   - Выбор модели из списка с размером: turbo 632MB (по умолчанию), large-v3 626MB, small, base. Скачивание с прогрессом через WhisperKit/HF.
   - Язык: ru (по умолчанию), en, авто.
   - Ускоритель: Neural Engine (по умолчанию), GPU, CPU. Это ModelComputeOptions для энкодера и декодера.
   - Смена ускорителя или модели требует перекомпиляции CoreML. Первый раз до ~3 мин, показывать «Подготовка модели…» с таймером.
   - **Кнопка «Тест скорости»**:
     - запись 5 с с микрофона (или встроенный образец);
     - прогон на каждом ускорителе;
     - таблица «загрузка, с / распознавание, с / текст»;
     - кнопка «Использовать лучший».

     Честно предупредить, что первый прогон каждого ускорителя долгий из-за компиляции.
9. **Автозапуск при входе** (включено по умолчанию): SMAppService.mainApp. Старый LaunchAgent прототипа не трогать, его уберёт главная сессия.
10. **Обновления.**
    - Sparkle 2 через SPM.
    - Лента обновлений: `https://github.com/vlad-anisov/Speak2Text/releases/latest/download/appcast.xml`.
    - Ключ EdDSA: `generate_keys` из Sparkle, приватный ключ в Keychain, публичный ключ в Info.plist (`SUPublicEDKey`).
    - Скрипт `scripts/release.sh <версия>`: сборка, zip, подпись Sparkle, appcast.xml в `dist/`. Ничего не публикует.
    - Если Sparkle не собирается без Xcode, запасной вариант: проверка GitHub Releases API, а в меню «Доступна версия X» → открыть страницу релиза.
11. **Звуки старта и стопа** (выключено по умолчанию): системные «Tink»/«Pop».
12. **Лог**: `~/Library/Logs/Speak2Text/speak2text.log`. Формат строк как в прототипе: audio, final_wait, len, text.

## Настройки — окно
Одно минималистичное SwiftUI-окно с вкладками:
- **Основные**: клавиша, режим, язык, заглушение, плашка, звуки, автозапуск;
- **Модель**: модель, ускоритель, тест;
- **Словарь**;
- **О программе**: версия, «Проверить обновления», ссылка на GitHub.

Хранение — UserDefaults. Изменения применяются сразу, без перезапуска.

`Resources/AppIcon.icns` и `Resources/MenuBarIcon*.png` (template). Генерируются скриптом `scripts/make_icon.swift`.
